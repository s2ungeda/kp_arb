완료라고 하기 전에 아래를 해 줘. 쉬운 말로.

1. 요구사항 대조표
   내가 요청한 항목을 하나씩 나열하고, 항목마다 이렇게 적어.
   - 어느 파일의 어느 함수에서 구현했는지
   - 어느 테스트가 그것을 확인하는지 (없으면 "테스트 없음"이라고 쓰고 이유)
   - 화면처럼 테스트로 못 잡는 것은 "사람이 확인할 것"으로 표시

2. 솔직한 목록
   - 요청했는데 안 했거나 일부만 한 것
   - 요청하지 않았는데 고친 것
   - 추측으로 채운 것, 임시값이나 빈 결과로 둔 것
   - 내가 확인하지 못한 것

3. 독립 검토
   서브에이전트에게 내 요구사항 원문과 git diff 만 넘겨. 네 작업 과정은 넘기지 마.
   서브에이전트는 읽기만 하고, 요구사항과 다르게 구현된 것, 빠진 경우, 기존 기능에 영향을 주는 것을 찾는다.
   지적 목록과 각 지적을 어떻게 처리했는지 보여 줘.

4. 사람이 확인할 순서
   내가 직접 띄워서 볼 것을 순서대로 적어 줘. 무엇을 누르고, 무엇이 보여야 정상인지.
