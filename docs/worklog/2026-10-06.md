## 1. 메인 메뉴 재구성 — 파일 / 주문 / 시세 (DESIGN-ui.md §7.1)

  시세 메뉴에는 시세표, HL 실시간 체결. 나머지는 주문 메뉴로."
- `main_window.py`: 파일(공통설정·화면 구성 되돌리기) / 주문(체결쏴 2종·HL 일반주문·주문 리스트·원달러선물 동시호가·FX 노출
  감시) / 시세(시세표·HL 실시간 체결). 코어 메뉴와 `start_core`/`stop_core` 삭제(코어는 메인과 함께 시작·종료, 자동 재기동
  그대로). 미접속 문구 "메뉴 ▸ 코어 ▸ 코어 시작" → "자동 재시동 대기(안 오르면 메인을 다시 시작)".
