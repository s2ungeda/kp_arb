# 답변

1. 정방향 진입 : -HP(=HL)/+S -> HL 매도 LS(주식) 매수 , 청산 : +HP/-S : HL 매수, LS 매도
   
   진입수치가 설정수치보다 높으면 LS 매수, HL 매도
   청산수치가 설정수치보다 낮으면 LS 매도, HL 매수

   즉, HL 과 LS 의 스프레드 값이 클때(HL 이 LS 보다 고평가 되어 있을때) 진입,  스프레드 값이 작아지면 청산   

   역방향 진입 : +HP(=HL)/-S -> HL 매수 LS(주식) 매도 , 청산 : -HP/+S : HL 매도, LS 매수
   스프레드 차가 클때 진입하는건 맞지만 정방향과 반대로 
   LS 가 HL 보다 고평가 되어 있을때 진입, 줄어들때 청산

1. 정장향/역방향 각 세트는 1회주문수량을 통해 est-price 를 구하고 이를 통해 실시간 진입, 청산 수치를 실시간으로 계산한다.
   발주조건
   - 정방향 진입 =  실시간 수치 > 설정한 수치(컬럼 이름: -HP/+S);
   - 정방향 청산 =  실시간 수치 < 설정한 수치(컬럼 이름: +HP/+S);

   - 역방향 진입 =  실시간 수치 < 설정한 수치(컬럼 이름: +HP/-S);
   - 역방향 청산 =  실시간 수치 > 설정한 수치(컬럼 이름: -HP/+S);   

2. 발주조건이 됐을때 HL 과 LS 에 동시에 주문, 
    - 양쪽모두 체결 확인 후 다음 주문 발주    
    - 어느 한쪽이 미체결 혹은 일부 체결시 : 시스템 멈추고 사용자 알람

3. 진입으로 체결되면 RT선진입 값은 늘어가고,  청산 되면 RT선진입 이 줄어들것이다.
   진입은 목표진수량보다 크면 안되고, 청산은 RT선진입 >= 1회주문수량보다 일때 해야 한다.
   RT선진입 누적·목표수량 도달 시 에도 계산 주문시도를 해야한다. 이유는 청산에 의해서 RT선진입 수량이 줄어들수 있으므로

4. 체결차는 : 주식잔고(매도면 - 표기)  + HP 잔고(매도면 - 표기)
   체결차 발생시  시스템 멈추고 사용자 알람.  ( 재주문이나 추가 주문은 하지 않음,사용자가 수동으로 알아서 주문 수행 ) 

5. S 제외 = HL만 발주 맞음, 주문가능시간 2구간 각 구간 확정

기타
- 화면구성이 수정되었다. png 파일 다시 봐야 함.
- 진입한도를 없애고, 세트설정에 전환딜레이 초 가 추가됨.


# 화면 설명
 
 - '적'버튼 : 선택한 종목, 호가단위 시세 수신 그리고 상단에 모니터링 수치(정방향, 역방향 진입 청산) 표시 단 기준수량이 0 보다 클때만
 - 공통설정 표시: 주문가능시간과 S주문 제외 정보 표시 (수정은 설정창에서만)
 - 정방향 그리드 설명
   1. 진입, 청산 수치인 '-HP/+S','+HP/-S' 컬럼만 수정 가능, 나머지는 세트설정창에서 설정(-HP/+S','+HP/-S' 도 세트설정에서 수정 가능)
      세틀설정창에서의 수정은 자동주문일때도 가능  
   2. 진입 자동주문일때는 진입수치 수정 불가, 청산 자동주문 일때는 청산 수치 수정 불가.
   3. 전환딜레이: 진입 마지막 체결후 N초 이후에 청산 주문 가능, 반대로 청산 마지막 체결 이후 N초 이후에 진입 가능
   3. 진입, 청산 버튼 : 목표수량과 1회주문수량 진입, 청산 수치 입력여부 판단 후 자동주문 실행
   4, 진입/청산이 체결될때마다 후 누적 결과를 그리드에 표시      
      진입의 경우  
      -HP : 누적매도체결 수량, +S: 누적매수체결수량, -환: 원달러선물 상대호가가격(호가 없을시 직전종가)*HP체결수량 의 누적평균
      sprd: 위 수치를 토대로 누적 스프레드 계산.
- 역방향은 정방향의 반대 개념으로      

- 그리드 위에 있는 진입/청산  clear 버튼 : 매매결과를 누적해서 보여주던 데이터를 0 으로 초기화.
