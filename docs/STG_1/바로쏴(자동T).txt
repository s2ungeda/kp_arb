# 클로드 코드 질문

1. (각 3~4줄): 정방향·역방향이 각각 무슨 포지션이고 언제 진입/청산하나. (예: 정방향 = HL 숏 + 주식 융자매수, 괴리 벌어지면 진입)
2. 판정 규칙 (부등호·공식 정확히): 스프레드가 기준값과 어느 방향으로 비교돼 발주되나.  
   진입/청산 스프레드는 방금 바꾼 **est 기반(§6.1-2)**을 그대로 쓰나? 목업 값(정방향 진입 0.5/0.7/1.0, 역방향 −1.5/−1.2/−0.9)의 부호 의미.
3. 실행 세부: 동시 taker 발주 순서, 한쪽 거부·부분체결 시 처리, 목표수량 도달 시 동작.

# 답변

1. 정방향 진입 : -HP(=HL)/+S -> HL 매도 LS(주식) 매수 , 청산 : +HP/-S : HL 매수, LS 매도
   
   진입수치가 설정수치보다 높으면 LS 매수, HL 매도
   청산수치가 설정수치보다 낮으면 LS 매도, HL 매수

   즉, HL 과 LS 의 스프레드 값이 클때(HL 이 LS 보다 고평가 되어 있을때) 진입,  스프레드 값이 작아지면 청산   

   역방향 진입 : +HP(=HL)/-S -> HL 매수 LS(주식) 매도 , 청산 : -HP/+S : HL 매도, LS 매수
   스프레드 차가 클때 진입하는건 맞지만 정방향과 반대로 
   LS 가 HL 보다 고평가 되어 있을때 진입, 줄어들때 청산

2. 각 세트는 1회주문수량을 통해 est-price 를 구하고 이를 통해 실시간 진입, 청산 수치를 실시간으로 계산한다.
   정방향 진입 =  실시간 수치 > 설정한 수치(컬럼 이름: -HP/+S);
   정방향 청산 =  실시간 수치 < 설정한 수치(컬럼 이름: +HP/+S);

   역방향 진입 =  실시간 수치 < 설정한 수치(컬럼 이름: +HP/-S);
   역방향 청산 =  실시간 수치 > 설정한 수치(컬럼 이름: -HP/+S);   

3. 실행세부

   발주조건이 됐을때 HL 과 LS 에 동시에 주문, 
    - 양쪽모두 체결 확인 후 다음 주문 발주
    - 어느 한쪽이 미체결 혹은 일부 체결시 : 시스템 멈추고 사용자 알람
